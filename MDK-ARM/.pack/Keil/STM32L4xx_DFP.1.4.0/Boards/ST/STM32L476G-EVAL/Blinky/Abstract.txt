The 'RTX_Blinky' project is a simple CMSIS RTOS Kernel based example for
ST 'STM32L476ZG' microcontroller using ST 'STM32L476G-EVAL' Evaluation Board.
Compliant to Cortex Microcontroller Software Interface Standard (CMSIS).

Example functionality:
 - Clock Settings:
   - MSI     =           4.00 MHz
   - SYSCLK  =           4.00 MHz

 - 1 LED blinks with a fixed speed.
 - blinking is paused while holding down Tamper button.


The Blinky program is available in different targets:

  STM32L476 Flash:  runs from Internal Flash located on chip
                    (used for production or target debugging)

  STM32L476 RAM:    runs from Internal RAM located on chip
                    (may be used for target debugging)
